## Kaip paleisti Selenium testus

Pirmiausia reikia įsidiegti ir susikonfigūruoti Selenium savo kompiuteryje.
Pagal operacinę sistemą reikia pasirinkti atitinkamą chromedriver versiją ir ją įlieti į PATH.

Komandinėje eilutėje reikia įvesti komandas
```bash
python3 test2.py
```

```bash
python3 test3.py
```
